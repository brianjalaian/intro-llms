# Introduction to Large Language Models

Course website by Dr. Brian Jalaian: pages (MyST / Jupyter Book 2), slides and notebooks.

- `index.md`, `week-N/`: pages and notebooks
- `slides/week-N/index.html`: finished lecture slides, one self-contained file each
- `assets/`, `static/fonts/`: look of the site

Build: `python3 tools/build.py` (needs `jupyter-book` 2). Preview: `python3 tools/serve.py`, then http://localhost:3208/llm/

Fonts: Fraunces, Geist and Geist Mono (SIL Open Font License).
