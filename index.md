You type words. The model sees numbers. Over eight weeks you follow those numbers all the way through: cut from text, related to each other by attention, trained, adapted and tested. You write small pieces of code at every step, and finish with a project of your own.

**You need:** basic Python. No machine learning background. Every notebook runs on a free CPU unless its page says otherwise.

[Start with Week 1](week-1/index.md)

## Schedule

| Week | Topic | What you do |
|:--|:--|:--|
| [1](week-1/index.md) | From text to tokens to vectors | Build a tokenizer, look up embeddings |
| 2 | Attention, in pictures and in code | Fill-in-the-blank notebook |
| 3 | The GPT block and a tiny GPT | Train a tiny model |
| 4 | Training and generating text | Experiment with loss and sampling |
| 5 | Using pretrained models | Guided fine-tuning |
| 6 | Testing models, and running them efficiently | Short evaluation report, project kickoff |
| 7 | Project week | Build and test a small project |
| 8 | Project week | Present it |

## How each week works

1. **Watch** the short video.
2. **Read** the slides on the week's page.
3. **Do** the notebook. Checks tell you when each blank is right.
4. **Explain** the idea in your own words. If you can't yet, that's the part to revisit.
